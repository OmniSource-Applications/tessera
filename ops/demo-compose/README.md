# Demo data stack (Cassandra + Oracle + PostGIS + Elasticsearch)

This compose stack gives you **four databases with seed data** to validate your "connections + flow" end‑to‑end.

## Quick start

```bash
cd demo-compose
docker compose up -d
# watch logs while initializers run
docker compose logs -f cassandra_init oracle elasticsearch_init postgis
```

Initializers (`cassandra_init`, `elasticsearch_init`) run once and exit.

## What demo data gets created?

### PostGIS
- Enables extensions: `postgis`, `uuid-ossp`
- Table: `places(id uuid, name text, category text, geom geometry(Point, 4326))`
- Table: `routes(id uuid, name text, geom geometry(LineString, 4326))`
- Table: `areas(id uuid, name text, geom geometry(Polygon, 4326))`
- Inserts a handful of rows around Colorado Springs + a sample route/polygon.

### Cassandra
Keyspace: `demo`
- Table: `devices_by_id(device_id text PRIMARY KEY, name text, lat double, lon double, updated_at timestamp)`
- Table: `events_by_device(device_id text, ts timestamp, type text, payload text, PRIMARY KEY (device_id, ts)) WITH CLUSTERING ORDER BY (ts DESC)`
- Seeds a few devices + events.

### Oracle
Schema (as `demo` user):
- Table: `DEMO_PLACES(ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, NAME VARCHAR2(200), CATEGORY VARCHAR2(50), LAT NUMBER(10,6), LON NUMBER(10,6))`
- Table: `DEMO_EVENTS(ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, DEVICE_ID VARCHAR2(64), EVENT_TYPE VARCHAR2(50), EVENT_TS TIMESTAMP, PAYLOAD CLOB)`
- Seeds a few rows.

### Elasticsearch
- Index: `demo-places` (geo_point `location`)
- Index: `demo-events` (keyword `device_id`, date `ts`)
- Seeds a few documents that align with the DB rows.

## Handy smoke tests

### PostGIS
```bash
psql "postgresql://demo:demo@localhost:5433/demo" -c "select name, st_astext(geom) from places;"
```

### Cassandra
```bash
docker exec -it demo_cassandra cqlsh -e "SELECT * FROM demo.devices_by_id;"
```

### Oracle
```bash
docker exec -it demo_oracle sqlplus demo/demo@//localhost:1521/FREEPDB1 <<'SQL'
SELECT * FROM DEMO_PLACES;
SQL
```

### Elasticsearch
```bash
curl -s http://localhost:9200/demo-places/_search?pretty
```
