Developer Quick Reference

Authentication

Include your API key in the request header using either format:

Authorization: Bearer tsk_your_key_here
# or
X-API-Key: tsk_your_key_here

Rate Limits

Each key has an independent rate limit (requests per minute). Response headers include: X-RateLimit-Limit, X-RateLimit-Remaining, Retry-After.

Example: Execute a Catalog Query

curl -X POST /tessera/api/queries/features.by_bbox/execute \
  -H "Authorization: Bearer tsk_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "minLon": -74.1, "minLat": 40.6,
    "maxLon": -73.8, "maxLat": 40.9,
    "limit": 100
  }'

Available API Endpoints

GET /api/queries — list catalog queries
POST /api/queries/{name}/execute — execute a query
GET /api/stream/sse — SSE stream
GET /api/stream/poll — polling delta
GET /api/builder/tables — schema metadata
POST /api/keys — create key (programmatic)

Scopes

QUERY_READ List queries
QUERY_EXECUTE Execute queries
SOURCES_READ List sources
SOURCES_WRITE Manage sources
STREAM_READ Stream access
LAYERS_READ Read layers
ADMIN Full access
